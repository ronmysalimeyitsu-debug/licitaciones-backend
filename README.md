# 🏛️ Backend API - Sistema de Licitaciones (MVP)

API REST desarrollada con **FastAPI**, **PostgreSQL (Supabase)** y **SQLAlchemy**, diseñada bajo una arquitectura desacoplada (*Headless Backend*) para dar soporte multiplataforma (**Web/HTML, iOS y Android**).

---

## 🚀 Tecnologías Utilizadas
* **FastAPI:** Framework web moderno de alto rendimiento para Python.
* **SQLAlchemy:** ORM robusto para el mapeo objeto-relacional y gestión de base de datos.
* **PostgreSQL (Supabase):** Motor de base de datos relacional en la nube.
* **Uvicorn:** Servidor ASGI ultrarrápido.
